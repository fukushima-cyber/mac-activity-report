# Mac操作ログ日次分析

対象日: {{DATE}}
ログ格納フォルダ: {{SHARED_DRIVE_PATH}}

## 手順

1. `{{SHARED_DRIVE_PATH}}` 内にある `{{DATE}}_*.json` というファイルを**すべて**読む。1ファイル=1社員の1日分のウィンドウ操作ログ(アプリ名・ウィンドウタイトル・継続秒数の時系列)。
2. ファイルが1つも無ければ、`[]` とだけ出力して終了する(他には何も書かない)。
3. 社員ごとに、そのログから以下を作る。**自分で無いことを補って書かない。ログに根拠が無い推測は「不明」と書く**:
   - **summary(作業内容の要約)**: 時系列を見て「いつ頃、何のアプリ/サイトで、具体的に何をしていたか」を3〜6行程度で。可能ならブラウザのタブ内容・ドキュメント名等の固有名詞、登場する人物名も含めて具体的に書く(匿名化しない)
   - **waste_notes(無駄・非効率が疑われる点)**: 同じアプリ間を頻繁に往復している、特定アプリに長時間連続で張り付いている等、ログから読み取れる客観的なパターンのみ書く。「サボっている」等の断定はしない
   - **automation_notes(自動化できそうな作業)**: 繰り返しパターンが見えた場合のみ具体的に書く。無ければ「該当なし」
   - **active_hours(稼働時間)**: JSON中の `active_seconds` を時間に換算(小数1桁)
   - **window_count(ウィンドウ切替回数)**: JSON中の `window_count`
4. 同じJSONの`windows`配列から、その社員の**1時間ごとのタイムライン**を作る(JST基準)。稼働が無い時間帯は飛ばす。各時間帯について:
   - duration: その1時間内の`duration_seconds`合計(「45分」のように分単位で読みやすく)
   - main_app: その1時間で最も合計時間が長かった`app`
   - description: ウィンドウタイトルから読み取れる具体的な作業を1〜2文で。固有名詞(サイト名・ドキュメント名・人物名)をそのまま使う。ログから読み取れない部分は書かない
5. その日の流れの補足を2〜3行で作る(day_note。午前/午後で何が中心だったか、まとまった集中時間があったか等)

## 出力形式

**説明・前置き・後書きを一切書かず、以下のJSON配列だけを出力する。** 1要素=1社員。

```json
[
  {
    "employee_slug": "<JSON中のemployeeの値>",
    "employee_name": "<社員名>",
    "active_hours": 1.0,
    "window_count": 222,
    "summary": "...",
    "waste_notes": "...",
    "automation_notes": "...",
    "day_note": "...",
    "timeline": [
      { "time_range": "18:00-19:00", "duration": "42分", "main_app": "LINE", "description": "..." }
    ]
  }
]
```
