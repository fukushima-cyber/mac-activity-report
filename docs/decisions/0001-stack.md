# 0001: 技術選定

## 状況

社員数人〜十数人のMac操作ログを自動記録し、AIが作業内容を要約してNotionに日次レポートしたい。リモート/オフィス混在。既製OSS(ActivityWatch, Cattr)を調査したが、
「自動でウィンドウ内容から具体的な作業を判定→複数人集約→AI要約」を一体で満たすものは無かった(2026-08-28時点)。

## 選択肢と決定

| 項目 | 決定 | 理由 |
|---|---|---|
| 記録 | ActivityWatch(OSS, Homebrew cask) | ウィンドウタイトル・URL自動取得の実装が既に成熟。自作しない |
| スクリーンショット | 使わない(v1) | window titleの時系列だけでAIによる具体的な要約が十分機能することを実データで確認済み。処理コストと画面内機密の写り込みリスクを避ける |
| 社員Mac→集約 | Google共有ドライブ(既存Workspace) | 新規インフラ・APIキー不要。リモート/オフィス問わず同期する |
| 要約・Notion投稿 | 管理者Macでの`claude -p`(既存ログイン、非対話実行) | 検証済み: ヘッドレス実行でもNotion MCP接続が有効。新規Anthropic/Notion APIキーの発行が不要になった |
| スクリプト | tsx + Node(記録側)、shell(実行オーケストレーション) | dev-brain既定(単発スクリプトはtsx+Node)に準拠 |
| スケジューリング | launchd(各Mac) | macOSローカル完結。社員Mac=記録のみ、管理者Mac=記録+集計の二役 |

## 保留・今後の検討

- 第三者名の匿名化ルールは実装時のデフォルト。運用しながら調整
- 精度不足ならスクリーンショット追加を検討(その場合は保存期間・閲覧範囲を別途設計)
